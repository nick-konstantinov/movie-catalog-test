1. **Как вы можете описать процесс распространения событий в JavaScript (Event Propagation)? Расскажите о его основных фазах.
   Какие есть способы применения знаний о фазах рааспространения событий на практике?**

В JavaScript распространение событий проходит через DOM в три фазы:
1. Capturing phase (фаза захвата) - событие идёт сверху вниз от window к целевому элементу. Если обработчик установлен с { capture: true }, он срабатывает на этой фазе.
2. Target phase (фаза цели) - событие достигает целевого элемента (event.target). Все обычные обработчики на этом элементе срабатывают здесь.
3. Bubbling phase (фаза всплытия) — событие идёт обратно вверх к родителям. Большинство событий по умолчанию всплывают, но есть исключения (focus, blur, mouseenter и т.д.).

Это позволяет эффективно использовать делегирование событий: один обработчик на родителе обрабатывает множество потомков. Также мы можем контролировать порядок срабатывания через { capture: true } и останавливать распространение с помощью stopPropagation() или stopImmediatePropagation(), если нужно, чтобы событие не дошло до других элементов.

2. **Расскажите, что такое Promise в JavaScript, как он работает, какие основные состояния у него бывают? Каким еще способом можно обработать асинхронный код? Какую роль в асинхронности играет событийный цикл (Event Loop)?**

Promise - это объект, который представляет результат асинхронной операции и позволяет работать с ним после завершения. У него есть три состояния:
- pending — операция ещё выполняется,
- fulfilled — успешно завершена,
- rejected — произошла ошибка.

Асинхронный код можно обрабатывать через "then/catch" или через "async/await" для более читаемого синтаксиса.

Event Loop - это механизм, который обеспечивает выполнение асинхронного кода после завершения текущего синхронного кода, без блокировки потока. Так как JS однопоточный, поэтому синхронный код выполняется первым, а асинхронные задачи помещаются в task queue или microtask queue. Промисы попадают в очередь микротасок, поэтому их обработчики выполняются раньше, чем обычные таймауты. Это важно для понимания порядка выполнения асинхронного кода.

3. **Что такое ООП, и какие его ключевые принципы вы могли бы описать? При объяснении приводите примеры. Максимально подробно расскажите о том, как ООП реализовано в JavaScript**

Объектно-ориентированное программирование - это подход, где основной единицей являются объекты с состоянием (свойства) и поведением (методы).

Ключевые принципы:
1. Инкапсуляция - скрытие деталей реализации и предоставление публичного интерфейса. В JS приватные поля можно объявлять через # или замыкания.

Пример:

```cpp
class User {
  #password;
  constructor(name, password) {
    this.name = name;
    this.#password = password;
  }
  
  checkPassword(pw) {
    return this.#password === pw;
  }
}

const user = new User('Alice', '1234');
console.log(user.name); // Alice
console.log(user.checkPassword('1234')); // true
console.log(user.#password); // error
```

2. Наследование - позволяет создавать новые классы на основе существующих (через extends), повторно использовать код.

Пример:

```cpp
class Animal {
  constructor(name) { this.name = name; }
  speak() { console.log(`${this.name} says`); }
}

class Dog extends Animal {
  speak() { console.log(`${this.name} says Gav!`); }
}

const dog = new Dog('Gray');
dog.speak(); // Gray says Gav!
```

3. Полиморфизм - один и тот же метод работает по-разному для разных объектов. Позволяет писать более универсальный код.

Пример:

```cpp
const animals = [new Animal('Main'), new Dog('Gray')];
animals.forEach(a => a.speak());
// Output:
// Main says
// Gray says Gav!
```

4. Абстракция - выделение важных характеристик объекта и сокрытие ненужных деталей. Достигается через публичные методы класса, которые управляют приватными данными.

Пример:

```cpp
class BankAccount {
  #balance = 0;
  
  deposit(amount) {
    this.#balance += amount;
  }
  
  withdraw(amount) {
    if (amount <= this.#balance) {
      this.#balance -= amount;
    }
  }
  
  getBalance() {
    return this.#balance;
  }
}

const account = new BankAccount();
account.deposit(100);
account.withdraw(30);
console.log(account.getBalance()); // 70
```

Особенности ООП в JavaScript:
- классы ES6 - это синтаксический сахар над прототипами, т.к. JS прототипно-ориентированный;
- поддерживаются геттеры/сеттеры, приватные поля, статические методы и методы экземпляров.

4. **Опишите максимально детально, как браузер обрабатывает URL, начиная с момента его ввода в адресную строку и заканчивая отображением страницы. Какие технологии позволяют ускорить процесс? Какие проблемы (безопастность, междоменное взаимодействие) могут возникать в процессе?**

Когда пользователь вводит URL, браузер проходит несколько этапов:
1. DNS Lookup - браузер определяет IP сервера через кэш, систему или внешний DNS.
2. Установка соединения - TCP handshake, а для HTTPS ещё TLS handshake для шифрования и проверки сертификата.
3. HTTP-запрос - отправка GET/POST на сервер и получение HTML с заголовками и статусом.
4. Парсинг и построение DOM - браузер строит DOM из HTML, параллельно загружает CSS и строит CSSOM.
5. Render Tree, Layout, Paint - браузер объединяет DOM и CSSOM в Render Tree, рассчитывает расположение элементов (layout) и отрисовывает их на экране (paint).
6. Выполнение JS - скрипты могут модифицировать DOM, блокируют рендер, если не используют async или defer.

Для ускорения загрузки используют кэширование, CDN, lazy-loading и предзагрузку ресурсов.

Основные проблемы:
- междоменные ограничения (CORS),
- уязвимости (XSS, CSRF),
- смешанный контент (HTTP на HTTPS)
- ошибки сертификатов TLS
